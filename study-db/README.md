# Study DB

데이터베이스의 주요 특성과 Spring Data JPA의 동작을 예제와 테스트로 학습하는 모듈입니다.

## 모듈 학습 범위

- 데이터베이스 동시성 제어
- 트랜잭션과 격리 수준
- 낙관적 락과 비관적 락
- 인덱스와 쿼리 실행 계획
- 데드락과 락 타임아웃

## 현재 학습 주제: 낙관적 락과 비관적 락

재고가 10개인 하나의 상품에 5개 요청이 동시에 접근하는 상황을 검증합니다.

### 낙관적 락

- `@Version`을 이용한 엔티티 버전 관리
- 5개 트랜잭션의 동일 버전 조회
- 1개 트랜잭션 커밋 성공
- 4개 트랜잭션 버전 충돌
- 최종 재고 9개, 버전 1

### 비관적 락

- `PESSIMISTIC_WRITE`를 이용한 데이터베이스 행 잠금
- 첫 번째 트랜잭션의 쓰기 락 선점
- 나머지 4개 트랜잭션의 락 해제 대기
- 락 획득 순서에 따른 순차적 재고 차감
- 최종 재고 5개, 버전 5

## 테스트 구성

- `@DataJpaTest`를 이용한 JPA 슬라이스 테스트
- H2 인메모리 데이터베이스
- `TransactionTemplate`을 이용한 스레드별 독립 트랜잭션
- `CountDownLatch`를 이용한 동시 실행 시점 제어
- `ExecutorService`를 이용한 5개 요청의 병렬 실행

## 실행

```shell
./gradlew :study-db:test
```

> H2는 학습과 자동화 테스트를 위한 인메모리 데이터베이스입니다. 실제 운영 데이터베이스에서는 락 대기 순서와 타임아웃 등의 세부 동작이 다를 수 있습니다.
